# WP3 — Storage v19 Implementation Plan

**Goal:** Ship one atomic v19 upgrade on both platforms, preserve v18 evidence and vectors, and expose tested folder, inventory, revision, generation, job, coverage and settings APIs without breaking existing ingestion or chat.

**Architecture:** SQLite owns durable state; Core owns validation and transaction boundaries. Both implementations execute the same logical schema and fixture scenarios. New revisions and active manifests are immutable. Publication inserts the complete chunk set and changes the published pointer in one fenced transaction. A generation is built beside the active generation, then activated atomically. Migration construction is tested before registration; the final integration tasks register v19 and switch existing callers together.

**Tech Stack:** Swift 6, Foundation, CryptoKit, GRDB, XCTest; .NET 10, Microsoft.Data.Sqlite, Dapper, System.Text.Json, xUnit; Python 3 sqlite3 for deterministic fixture construction. No additional dependency.

**Spec:** `docs/superpowers/specs/2026-10-09-folder-chat-multilingual-rag-design.md` §4.1, §6.1, §6.3, §8.7. **Master:** `docs/superpowers/plans/2026-10-09-folder-chat-master-plan.md`. **Contracts:** `docs/contracts/folder-rag-v1.md` §1–4 and `docs/contracts/lang-detector-v1.md` §1–2 (NULL language versus `und`, scalar offsets). **Format exemplar:** `docs/superpowers/plans/2026-10-09-wp0-contracts.md`. This plan invokes no installed skill.

UPDATE ingest_jobs
SET state=CASE WHEN attempts>=5 THEN 'failed' ELSE 'queued' END,
    next_retry_at=$now + (30 * (1 << attempts)),
    lease_until=NULL,lease_token=NULL,error='leaseExpired'
WHERE state='running' AND lease_until<=$now;
-- Select first due job (optional id filter), then conditional UPDATE in same write transaction.
SELECT id FROM ingest_jobs
WHERE state='queued' AND attempts<5 AND next_retry_at<=$now
ORDER BY next_retry_at,id LIMIT 1;

    lease_until=$now+300,lease_token=$token,error=NULL
WHERE id=$id AND state='queued' AND attempts<5 AND next_retry_at<=$now;

SELECT id FROM ingest_jobs WHERE id=$id AND state='running'
    AND lease_token=$token AND lease_until>$now;
-- Renewal never changes attempts or the token.

WHERE id=$id AND state='running' AND lease_token=$token AND lease_until>$now;

Invalid/empty token rejects; worker tokens are new UUID strings for each claim, never reused. Recovery does not increment attempts. Lease check is strict `>`; exactly expired cannot publish. Pause accepts queued or running, clears lease/token, and does not refund an attempt; resume only paused, resets retry to now; cancel queued/running/paused, clears lease/token. Done/failed/cancelled are terminal; terminal resume throws invalidValue. The fenced cancel overload checks the running token and unexpired lease before cancellation and returns false for an old owner. Generic complete is permitted for scan/embed/gc; completing an extract job without publication is rejected invalidValue so a worker cannot mark incomplete extraction done.

`insertRevision`: validate source exists, hash nonempty, versions 1/1 or 1/2; allocate `coalesce(max(revision),0)+1` and insert, then set current pointer. `publishRevision`: failed fence returns false and makes no writes; target must equal `source:<id>`, kind extract and target_revision==revisionId. If a valid owner attempts a no-longer-current revision, mark its job cancelled and return false. Validate ownership and the entire chunk array before inserting. For version2 every span is nonnull, 0<=start<end<=scalar count, text bytes equal the scalar slice (Swift `.utf8.elementsEqual`, C# `StringComparison.Ordinal`; Swift canonical-equivalence `==` is not sufficient); ord is array index; lang allowed codes; inherited requires nonnull lang. Legacy version1 accepts only both-null spans. Reject duplicate publication (already referenced by published pointer or chunks exist); no second chunk set. Set published pointer/status ready/error NULL and finish the fenced job only after all inserts succeed. Any thrown validation/SQL error rolls back pointer, chunks and job completion.

`commitForegroundRevision` is a convenience **fenced** transaction: call private DB helpers to insert revision, enqueue a targeted extract job, claim that exact id with the supplied unique token, insert/publish chunk set and complete. All are in one transaction, never public-method nesting. This keeps manual import/note indexing working without a long-lived WP6 scheduler and without a token-free publication bypass.

```swift
public static func chunk(_ text: String, pageStarts: [(offset: Int, page: Int)] = [],
                         window: Int = 2048, overlap: Int = 256) -> [RevisionChunkDraft] {
    precondition(window > overlap && overlap >= 0)
    let s = Array(text.unicodeScalars)
    func space(_ value: UInt32) -> Bool {
        (9...13).contains(value) || [0x20,0x85,0xA0,0x1680,0x2028,0x2029,0x202F,0x205F,0x3000].contains(value)
            || (0x2000...0x200A).contains(value)
    }
    var result: [RevisionChunkDraft] = []
    var start = 0
    while start < s.count {
        var end = min(start + window, s.count)
        if end < s.count {
            var probe = end
            let floor = max(end - 200, start + 1)
            while probe > floor && !space(s[probe - 1].value) { probe -= 1 }
            if probe > floor { end = probe }
        }
        var lo = start, hi = end
        while lo < hi && space(s[lo].value) { lo += 1 }
        while hi > lo && space(s[hi - 1].value) { hi -= 1 }
        if lo < hi {
            result.append(RevisionChunkDraft(text: String(String.UnicodeScalarView(s[lo..<hi])),
                tokenCount: max(1, (hi - lo + 3) / 4),
                pageHint: pageStarts.last(where: { $0.offset <= lo })?.page,
                charStart: lo, charEnd: hi, lang: nil, langInherited: false))
        }
        if end == s.count { break }
        start = max(end - overlap, start + 1)
    }
    return result
}
```

```csharp
public static IReadOnlyList<RevisionChunkDraft> Chunk(string text,
    IReadOnlyList<(int Offset, int Page)>? pageStarts = null, int window = 2048, int overlap = 256)
{
    if (window <= overlap || overlap < 0) throw new ArgumentOutOfRangeException(nameof(window));
    var s = text.EnumerateRunes().ToArray();
    static bool Space(int v) => v is >= 9 and <= 13 or 0x20 or 0x85 or 0xA0 or 0x1680
        or 0x2028 or 0x2029 or 0x202F or 0x205F or 0x3000 or >= 0x2000 and <= 0x200A;
    var result = new List<RevisionChunkDraft>();
    int start = 0;
    while (start < s.Length)
    {
        int end = Math.Min(start + window, s.Length);
        if (end < s.Length)
        {
            int probe = end, floor = Math.Max(end - 200, start + 1);
            while (probe > floor && !Space(s[probe - 1].Value)) probe--;
            if (probe > floor) end = probe;
        }
        int lo = start, hi = end;
        while (lo < hi && Space(s[lo].Value)) lo++;
        while (hi > lo && Space(s[hi - 1].Value)) hi--;
        if (lo < hi)
        {
            int? page = null;
            if (pageStarts is not null)
                foreach (var p in pageStarts) if (p.Offset <= lo) page = p.Page;
            string slice = string.Concat(s.Skip(lo).Take(hi-lo).Select(r => r.ToString()));
            result.Add(new(slice, Math.Max(1, (hi-lo+3)/4), page, lo, hi, null, false));
        }
        if (end == s.Length) break;
        start = Math.Max(end-overlap, start+1);
    }
    return result;
}
